# AI/ML Computer Vision Pipeline: HeadCut Detection & Image Cropping

A modular computer vision system built to handle image quality verification (HeadCut detection) and dynamic smart cropping.

## Project Structure Overview

- `plans/`: Roadmap and phase-by-phase planning documentation.
- `dataset_utils.py`: Utilities for handling dataset loading, image verification, and preprocessing.
- `Candidate_Submission/`: Submission packages for Task 1 and Task 2.
- `web_dashboard/`: Interactive web application dashboard for live model testing and batch processing.

## Setup & Prerequisites

```bash
# Clone the repository
git clone https://github.com/arefinMilen/smart-vision-crop.git
cd smart-vision-crop

# Install dependencies
pip install -r Candidate_Submission/Task1_Solution/requirements.txt
```
